# 设计记录

## 端口转发引用已完成转发

### 目标

允许普通端口转发规则将出口引用到一条已保存的、已经绑定转发链的规则，而不是手工维护该规则入口的 IP 和端口。

例如，HeptaSkyIX 的入口规则引用 `Akari港新内网 / Onidel-SG`。面板将该引用解析为该链上规则当前的入口地址（如 `DataWave-HK:15000`）；后续由该链上规则转发至它配置的最终落地。

### 第一阶段范围

- 在出口目标中增加“引用已完成转发”模式。
- 持久化被引用规则的 ID，而非复制其 `targetIp:targetPort`。
- 在 Agent 下发前解析为被引用规则当前的入口地址及源端口。
- 被引用规则入口地址、端口或状态变化时，刷新所有依赖规则。
- 校验同一用户/授权范围、协议兼容性、启用状态和引用环；删除被引用规则前展示依赖并阻止或要求迁移。

### 非目标

第一阶段不实现“裸转发链作为中间段后再追加任意落地”。该行为应由创建或复用一条明确的链上结果规则实现，避免没有业务端口和最终目标的链路引用。
